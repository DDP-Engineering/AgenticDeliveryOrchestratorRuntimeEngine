# AEGIS 2.x Hard-Break Adaptation

Planning material for **ADORE 2.0.0**: the no-compatibility adaptation of the
orchestrator to the AEGIS 2.x grouped CLI and 8-stage form-driven workflow.

- `ADORE_2.0_Adaptation_Plan.md` — the implementation plan (design
  decisions, work packages WP1–WP8, scope boundaries, risks).
- `AEGIS_2.1_Contract_Notes.md` — pinned snapshot of the AEGIS 2.1
  orchestrator-facing contract (CLI, envelope, exit codes, state files,
  blockers) the plan is built against.

Basis: AEGIS payload 2.1.0 / WAEGIS 1.1.0 (+ unreleased waivers and
`--quick`), ADORE 1.2.0 (+ unreleased Gitea support). Authored 2026-08-01.
