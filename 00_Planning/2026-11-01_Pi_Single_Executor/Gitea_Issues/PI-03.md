# [Pi] Remove OpenCode, Codex and Qwen Code support

Labels: P1, change. Part of [epic #50](http://192.168.1.15:3001/dpasare/AgenticDeliveryOrchestratorRuntimeEngine/issues/50). Depends on: [PI-02 #52](http://192.168.1.15:3001/dpasare/AgenticDeliveryOrchestratorRuntimeEngine/issues/52).

## Goal

Pi is the only coding agent. No other agent remains in code, configuration, image,
interface, tests or documentation, and there is no agent choice anywhere.

## Decisions

- No migration: a `config.toml`, profile or run state that mentions another agent
  is refused with a message naming the key and what to delete or fix (for example
  `[executor] unknown key 'opencode': remove it from config.toml`).
- Keep the internal executor interface with Pi as its only implementation; do not
  inline Pi into the orchestrator.
- OpenCode-only features (custom endpoint, model catalogue, endpoint probe, local
  OpenCode configuration isolation) are removed here; PI-04 rebuilds the endpoint
  feature for Pi. Until then local endpoints are not configurable (accepted).
- Host sign-in staging (copying agent auth files) is removed; PI-05 replaces it.

## Scope

Work through the inventory in `PLAN.md` section 5 (line numbers are from `946757e`
and may have moved):

- `adore/executor/launcher.py` OpenCode, Codex, Qwen classes and the selector.
- Presets in `adore/web/executor_configuration.py`, `adore/wizard.py`,
  `config.example.toml`.
- `adore/config.py` per-executor validation, OpenCode endpoint, default executor.
- `adore/web/model_connection.py` probes for other agents (keep or adapt the Pi one).
- Host sign-in staging in `orchestrator.py`, `execution.py`, `branding.py`,
  `web/executor_settings.py`.
- `adore/local_execution.py` OpenCode isolation and other agents' homes and auth paths.
- `adore/web/endpoint_probe.py`, `adore/opencode_catalogue.py`, OpenCode endpoint
  routes in `adore/web/app.py`, OpenCode checks in `adore/doctor.py`.
- `docker/Dockerfile.executor-base` layers and `docker/verify-runtime.sh` checks.
- Web: `executorSettings.ts`, `ExecutorCredentials.tsx`, `EnrollmentWizard.tsx`,
  `serverImages.ts`, `App.tsx`, `settings.ts`, `settingHelp.ts`, `i18n.ts`.
- Tests for removed behaviour (delete) and tests that loop over agents (reduce to Pi).
- Documentation: help (`executors.md`, `glossary.md`, `projects.md` x4 locales),
  `01_Documentation`, `05_SoftwareDocu`, `.agentic/knowledge`, requirements
  (retire the ones that only describe other agents).

Out: new provider/endpoint settings (PI-04), ChatGPT sign-in (PI-05).
