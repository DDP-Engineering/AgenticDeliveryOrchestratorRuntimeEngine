# [Pi] Web search, page reading and downloads behind an internet switch

Labels: P2, enhancement. Part of [epic #50](http://192.168.1.15:3001/dpasare/AgenticDeliveryOrchestratorRuntimeEngine/issues/50). Depends on: [PI-02 #52](http://192.168.1.15:3001/dpasare/AgenticDeliveryOrchestratorRuntimeEngine/issues/52), [PI-04 #54](http://192.168.1.15:3001/dpasare/AgenticDeliveryOrchestratorRuntimeEngine/issues/54).

## Goal

One project setting, "Internet access for the agent", decides what the agent can
reach. Off: only the model provider. On: the open internet, so the agent can search
the web, read pages and download libraries.

## Decisions

- `[executor] internet = false` maps to the container egress allowlist with the
  provider's host, or the custom endpoint's host, derived by ADORE; `true` maps to
  open egress. Reuse the existing `[container.egress]` machinery; the user sees only
  the switch.
- Default Off (owner decision, 2026-11-01).
- Web search and page reading come from the pinned `pi-web-access` extension,
  configured by ADORE: Exa without a key by default; optional Brave or Tavily key in
  the credential store (`[executor.web] search`).
- Downloads use `bash` (`curl`, `npm`, `pip`); no download tool is added.
- On a server-installed run the switch cannot be enforced; the interface says so.

## Scope

In: schema and validation; derived allowlist; ADORE-generated `pi-web-access`
configuration; Settings switch and search options (four locales, help) with a
warning when On that a malicious page could try to make the agent send its key or
the ChatGPT credential out; readiness check that reflects the switch.

Out: package caches and adaptive dependency installation (#26).

## Where to look

`adore/config.py` (`[container.egress]`), `adore/isolation.py` (egress and proxy),
`adore/executor/pi_rpc.py` (from PI-02), settings components in `web/src`,
`01_Documentation/Security_And_Credentials.md`.

## Acceptance criteria

- [ ] Off: the provider call works, `curl https://example.com` fails, web search
      fails with a clear message (tests with fakes; one live check in the PR).
- [ ] On: `web_search`, page reading and `npm install` / `pip install` work in a
      test project (live check in the PR).
- [ ] A custom endpoint's host is in the Off allowlist; a ChatGPT project's hosts too.
- [ ] The warning appears when On; a server-installed project shows the switch as
      not enforced.
- [ ] Docs, help, `CHANGELOG.md` and release note updated.
