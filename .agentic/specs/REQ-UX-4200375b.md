# Address every web view by a stable URL

This specification describes the current implemented contract.

## Behavior and boundaries

### [REQ-UX-4200375b](../requirements/ux/REQ-UX-4200375b.toml) — Address every web view by a stable URL

While a signed-in user moves between ADORE web views, the interface shall keep the address bar on a path URL that identifies the view and its project, tab or selected job, so that reloading the URL, opening it in a new tab after sign-in, or using browser Back and Forward shows the same view; unknown or unauthorized paths shall open Overview or the project list instead of a blank page.

Verification scope: Automated: unit tests of the pure route module parse and format every route in the spec, including query parameters, unknown paths and role fallbacks. Manual: in Chrome, open each route directly, reload it, follow a chain of views and step back and forward; open a project URL while signed out and confirm sign-in returns to it; open an admin URL as a developer and an unknown path, and confirm the fallback view.
