## Design

### Approach
REQ-FUNC-1ca885c7: add project_bundle.py to read a current exported ZIP through parse_recipe, validate complete closure/Compose and return exact config bytes plus Recipe. Reuse the existing effective-image resolver only for image correspondence.
REQ-UX-83494e0a: keep RawImportDialog with one file selector/confirmation; a discriminated in-memory document chooses the unchanged TOML routes or two new bundle routes.
### Interfaces and data
Two Admin+CSRF endpoints expose ordinary import-preview fields and bundle_revision; source is strict bounded base64. The revision hashes exact ZIP bytes, native import revision and observed catalog revisions. No new stored schema, migration or dependency.
REQ-FUNC-85d7e939: RecipeStore.preview_import validates current bindings; import_project locks its catalog, rechecks those revisions, writes only absent bindings and calls the existing guarded paused publisher. A conflicting bound root or conflicting implicit bundled root is refused; identical roots are reused. Existing supplemental associations remain unchanged and the root keeps embedded sources.
REQ-REL-1fe3164a: normal failure rolls back only exact newly-created associations, leaving immutable unreferenced objects harmless. Existing publisher owns profile/pause rollback. Catalog then enrollment then candidate-state locks avoid cycles with current profile-edit then catalog operations.
### Files and test seams
New project_bundle.py and test_project_bundle.py cover bounded current ZIP/graph/Compose validation. executor_recipes.py adds coordinated retention; API routes reuse _import_preview_identity/_inspect_project_import/_publish_paused without changing TOML behavior. test_web_bundle_import.py proves authority, exact roundtrip, concurrency/conflict/rollback boundaries. RawImportDialog/importCopy/errors plus import.spec.ts prove simple selection/cancel/stale/changed-file behavior. Four-locale Projects/Settings help, user/component docs, notes and current-state knowledge follow the implementation.
### Risks and open decisions
Untrusted ZIP expansion remains bounded and in memory. No archive scripts or image builds execute. Preparation-selected image validation may read pinned local Git sources, never the network. Existing server-location conflicts stay explicit. Process/power loss retains existing incomplete-profile refusal, without automatic recovery. No unresolved product decision.
### Requirement map
REQ-FUNC-1ca885c7: bounded pure preview and image/Compose closure.
REQ-FUNC-85d7e939: exact config/source publication and paused project.
REQ-REL-1fe3164a: snapshot CAS, existing root conflict and bounded rollback.
REQ-UX-83494e0a: current popup, exact-file single confirmation.
REQ-SEC-c3a134af: existing administrator and CSRF guards before parsing/retention.
