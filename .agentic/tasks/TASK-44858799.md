## Frame

Problem: ADORE cannot conduct any AEGIS task against AEGIS 0.16.0. OBSERVED:
  0.16.0 removed the quick path, the `path:` journal header and `advance
  --path`; a 0.16.0 journal decoded by `AegisClient._decode_task` raises
  "AEGIS task header is missing ['path']" (probe in a scratch repo,
  `aegis task --type fix` then `status --json`). OBSERVED: a legacy
  `path: quick` journal now advances frame -> specify, which
  `allowed_transition(..., "quick")` refuses.
Desired outcome: ADORE conducts AEGIS 0.16.0 tasks through the single stage
  order frame -> specify -> design -> build -> validate -> done (specify and
  design advanced one at a time, possibly as skipped), and the quick-label

## Design

**Approach**: remove the path dimension end to end instead of mapping it.
The client drops `QUICK_STAGES`/`QUICK_KINDS`, stops requiring the `path`
header key (a legacy `path:` line stays an ordinary bounded header value),
and `allowed_transition(previous, current)` /
`evidenced_transition(previous, current, log)` use `FULL_STAGES` only
(REQ-FUNC-16237c6d). `MINIMUM_SERIES` becomes (0, 16) because a 0.15 quick
journal would jump frame -> build without specify/design Log lines and be
refused mid-run; refusing at probe is the honest failure (REQ-FUNC-8472a560).
Rejected: keeping a quick sequence for legacy journals - AEGIS 0.16.0 itself
moves them through the single order, so ADORE would disagree with AEGIS.

**Interfaces and data**: `AegisTask.path` is removed; callers in
`orchestrator.py` stop passing a path. `RunState.aegis_path` is removed in
place (RULING-001); `from_dict` then refuses old state files through its
existing unknown-key error, and CHANGELOG names the state to delete. The
approval note loses its `- Path:` line. `[workflow] quick_label` is removed
from `WorkflowConfig`; an existing config key is refused by the existing
unknown-key check with "remove it from config.toml". The forge label
catalogue stops provisioning the quick label; the wizard stops asking for
it; the web settings key, copy, help and settings grouping drop it.

**Files and test seams**: `adore/aegis.py`, `adore/orchestrator.py`,
`adore/state.py`, `adore/config.py`, `adore/forge_labels.py`,
`adore/wizard.py`, `adore/prompts.py`, `prompts/stage/frame.md`,
`prompts/stage/active-task.md`, delete `prompts/stage/quick-label.md`;
`config.example.toml`; web `settingKeys.json`, `settings.ts`,
`settingHelp.ts`, `settingsCopy.ts`, `jobCopy.ts`, help en/fr/de/ro.
Tests: `test_aegis.py` (probe floor, transitions, decode with/without
path), `test_aegis_compatibility.py` with a new 0.16.0 fixture,
`test_orchestrator.py` (paths, prompts), `test_prompts.py` + baselines,
`test_config.py`, `test_forge_labels.py`, `test_wizard.py`,
`tests/supervisor_helper.py`, web settings tests if they list keys.

**Risks and open decisions**: stored run state becomes unsupported
(accepted, RULING-001). Prompt baselines change by design: frame text and
`active-task.md` lose the path; REQ-FUNC-14872c0d still holds for the new
fragments. Web bundle must be rebuilt after web source edits.

**Requirement map**: REQ-FUNC-8472a560 floor 0.16.0, probe tests;
REQ-FUNC-16237c6d single order, decode and transition tests;
REQ-FUNC-14872c0d prompt byte tests with new baselines; REQ-FUNC-8adb68f9
prompt contract test renamed from the quick hint; REQ-FUNC-ff7dad34 and
REQ-UX-1dcd528c delivery test covers full and skipped-stage journals;
REQ-UX-b758d2b7 timeline copy, no design impact beyond wording.
