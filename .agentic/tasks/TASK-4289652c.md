## Frame

Problem: on Verification the Validate setup and Check environment buttons stack with their results on separate lines, Review candidate sits apart from Back/Cancel, and the Enrollment complete screen lists labels in small monospace text pressed against Open project. STATED (with DCP screenshots): "la verification am 2 butoane - care nu-mi plac cum sunt aliniate ... Nu merge pusa eticheta cu raspunsul langa ele ... eventual si marcata ... Iar jos avem buton review candidate - nu putem avea continue? adica la fiecare etapa avem back, continue si cancel ... Si butoanele acestea sa fie in linie. De asemeni, in enrollment complete page - textul nu e aliniat si se suprapune - sunt diferite fonturi".
Desired outcome: each Verification action shows its result beside it as a marked badge (valid; verified/partial/failed/unverified); every step ends with Back, Continue (Create on the last step), Cancel in one row; the completion screen shows labels as chips with normal spacing.
Actors: administrators enrolling or cloning a project.
Primary scenario: Validate setup -> green "Structural setup valid" beside it -> Check environment -> amber "Partial ..." beside it -> Continue opens Review and create -> Create in the same row.
Examples: the DCP vera enrollment screenshots.
Counterexamples: no behavior change (same validations, review snapshot and creation); Import project config keeps its own button.
In scope: EnrollmentWizard.tsx (Verification rows, bottom actions, completion class), ForgeLabels.tsx chips, styles.css, e2e enrollment/transfer specs (Continue instead of Review candidate), help projects.md Verification row (four locales).
Out of scope: Import wizard; full suite (STATED: tests only at the end).
Constraints: keep accessible status announcements.
Success signals: targeted e2e green; screenshots of Verification and completion.
Evidence: OBSERVED step 4 rendered the buttons and `<p role="status">` lines separately and Review candidate inside the step; completion used `<code>` lists.
Assumptions: none. Unknowns: none. Decision-blocking questions: none.
