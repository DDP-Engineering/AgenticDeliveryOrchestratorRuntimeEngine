## Design

One executor_configuration helper validates exact selection JSON and writes default plus the selected command/model with the existing TOML scalar writer, verifying full parsed meaning. Other command entries remain intact. Public pending exposes the complete selection map, and reconstructs the candidate against the unchanged active revision before apply to reject unrelated or unsupported changes. Direct PUT requires pending review for selection/env list. Catalog advertises all supported agents and presets including missing tables; Settings row owns selection editor, with generic current-agent command/model labels and separate credential-name multi-select. Existing private credentials and model evidence retain their authority. SettingsList embeds connection/environment/auth content once in Agent and model; old executor routes normalize to Settings. External runtime definition/installation stays informational. Existing custom provider variable names can be retained/removed but new names come from known provider keys; forge variables remain refused. Expected seams: app.py/implementation_settings.py, new helper and frontend editor/copy, settings/routes/App/credentials/styles, API/helper/browser tests and affected user/component documentation. No agent children, no live model calls, no secret defaults.
