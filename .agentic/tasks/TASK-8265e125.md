## Design


D1 (REQ-DATA-d893df33): Profile adds validated display_name; absent legacy key falls back to name. Web identity PUT reloads metadata under config_edit_lock, preserving project_id and all path/owner keys. CLI rename remains its existing distinct contract.
D2 (REQ-FUNC-e8e0e304): ProfileStore.id_availability validates portable IDs/reserved policy, incomplete directories, case-fold collisions and corrupt metadata. Home-wide cross-process enrollment guard rechecks before exclusive directory creation; advisory availability never reserves a name.
D3 (REQ-REL-c598b075): API owns staged publication and rollback: lock enrollment -> exclusive final directory -> conductor lock -> validated config bytes -> pause -> metadata publication -> audit/response -> unlock. Worker discovery already requires metadata; no worker change needed. Imports lock retained external state and restore only the pause marker on failure, never history. Remove metadata before releasing the conductor lock. Corrupt leftovers remain blocked for manual recovery.
D4 (REQ-FUNC-3d8f6f5e): WizardSetup dataclass is an opt-in prepare-only output; skip all informational probes in this mode. Default wizard still probes and saves as before. HTTP setup-preview returns safe findings; ProjectInput forbids extras. Exact import keeps its legacy string issues alongside structured validation. Shared typed errors carry stable field/code without input echo.
D5 (REQ-DATA-70e5e3bb): readiness.json is profile-owned schema-1 evidence independent of runtime schema. Atomic unique-temp writes, strict read validation and identity/revision/time binding. Capture exact config bytes; recheck revision/identity under config_edit_lock before persisting. Existing explicit probes stay bounded and fakeable; none are added to reads/typing. Read models expose separate validation, pickup_state and verification.
D6 (REQ-SEC-61fb8552): reuse admin_mutation for all new routes, shared principal/grants for reads. Secret inspection walks TOML/inline JSON and credential URLs, allows only supported env references, never emits values. Persist only known redacted readiness fields.
