Desired outcome: STATED: automatic current account, advanced technical options and host clone folder choice, rebuilt/tested Windows/Linux delivery.
Actors: Administrator enrolling a project or editing its local executor; ADORE host filesystem; authenticated API.

## Design

REQ-UX-ec09a60a: LocalExecutorPicker retains installed selector/host/refresh as primary UI and places command/manual path plus wizard home/PATH/delegation children in closed details. Wizard sends current account; readonly discovered identity comes from existing endpoint. Saved configuration assertions remain preserved, with technical rows in closed Advanced. Keep model/auth/backend and container behavior.
REQ-FUNC-f47164f2: new host_folders module returns system, path, parent, roots, folders and truncated. GET /api/v1/host-folders is admin-only, no-store. Empty input defaults to OS home; absolute native path only, reject controls/relative/UNC/device/nonexistent/non-directory; bounded scans, directory names only, no shell/file contents/writes. OS errors become value-free typed HTTP failures.
Folder dialog uses showModal/focus restoration/Escape, request generation/abort guards, roots/parent navigation, editable location and optional single new child name. Choose returns existing directory or directory/child, without mkdir. Manual destination stays possible. Automatic/custom mode resets to repository-source proposed destination; typed draft persists while toggling Advanced and wizard steps.
Concurrency: stale folder reads cannot replace later navigation; cancelled dialog cannot mutate draft. Clone publication retains existing checks/review.
Compatibility: no persisted schema changes/dependencies; backend validation remains final authority. Windows drives and Linux root are host paths. Admin filesystem listing exposes names only, avoids symlink/reparse navigation and refuses network/device paths.
Test seams: offline TestClient with temporary directories and faked errors, denied roles, scan caps; browser mocked Windows/Linux and real fixture directories; four locales/mobile; packaged API acceptance on both OSes.
Expected files: EnrollmentWizard, LocalExecutorPicker, localExecution, App/settings, new HostFolderPicker/hostFolders/setupCopy and Python host_folders; tests/help/docs/release notes/static; Tools acceptance and Delivery artifacts.
Risks: inaccessible/missing custom directories and no detector response; keep explicit failure/manual choices. Linux delegation remains required and is explained in Advanced.
Open decisions: none. Budget: 150 minutes, 90 implementation/docs/test files, 5 review fix cycles; no model/provider calls.

### Proposed architecture - TASK-f3196d20

Enrollment -> HostFolderPicker -> authenticated host-folders -> bounded filesystem metadata.
Enrollment/Settings -> LocalExecutorPicker -> existing local-executors -> detected identity/installation -> reviewed configuration.
