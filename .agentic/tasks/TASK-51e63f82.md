## Design

REQ-UX-34718dd6: Shared config validates a nonempty list of bounded nonblank account strings with no whitespace/control or option prefixes. Web metadata marks only delivery.reviewers editable among lists. A dedicated TOML list writer parses the wire array, preserves unrelated text including CRLF, and replaces complete single/multiline reviewers arrays. Public candidate metadata uses canonical JSON and exact list/value equality; browser validator accepts arrays only for this key. UI textarea edits one account per line and serializes a list; reviewer label is localized consistently in row and review. Default/read-only array settings stay unchanged. Existing CSRF/admin/revision/idle/apply integrity checks remain authoritative.
Architecture: Admin textarea -> canonical list wire -> candidate list validator/writer -> existing reviewed apply -> Config -> conductor reviewer requests. No schema version or dependency changes.
Risk: Unsupported TOML key spelling must fail closed, never guess or replace adjacent keys. Usernames are validated locally; eligibility/notification remains forge owned.
