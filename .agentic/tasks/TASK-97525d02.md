## Design

### Approach

Projects owns modal visibility and opens guided EnrollmentWizard directly (REQ-UX-664b7fa0, REQ-UX-43f73ffd). Remove the retired transfer wrapper and its guided-only branches.

### Interfaces and data

Native dialog retains only a File and its validated identity, revision and text. A new File aborts and invalidates the previous preview. Import rereads the file and sends the exact reviewed candidate to the existing endpoint (REQ-UX-3b5b2257, REQ-DATA-71853fbc).

### Files and test seams

App, routes, modal, guided enrollment and localized copy. Browser cases cover dialog visibility, keyboard, errors, exact successful import and stale requests. Route tests cover former URLs. Guided enrollment tests prove the ordinary setup boundary.

### Risks and open decisions

Cancel and Escape discard validation. Publication is serialized and guarded until its result arrives. Session or route changes unmount the dialog. Existing APIs and store formats stay outside the change.

### Requirement map

The modal owns REQ-UX-3b5b2257 and REQ-DATA-71853fbc. Projects and routes own REQ-UX-664b7fa0. Direct enrollment owns REQ-UX-43f73ffd. REQ-UX-7d0b71c3 is retired.
