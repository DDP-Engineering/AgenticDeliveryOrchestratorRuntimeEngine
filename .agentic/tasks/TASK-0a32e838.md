Overview JobWorkspace omits its selector and retains only conditional worker faults; fixed Summary and Jobs untouched. Periodic Overview job reads use background flag, preserving only validated current renderKey rows while pending; every rejected read still clears attention/active. Scope/id/key changes hide old rows immediately. Hide Overview refresh timestamp; keep manual Refresh. No API/telemetry/clock-storage changes.
