Actors: administrators on global Statistics (All projects).

Out of scope: metrics APIs; full suite (STATED: at the end).

## Design

- D1 App: drop the metrics scope-note paragraph; metricsTabs without "projects"; an effect maps a stale "projects" tab to Summary everywhere.
- D2 routes: normalize /metrics?tab=projects to Summary for every role.
- D3 tables: Summary per-project = Project (repo hint) | Started | Completed | Failed | Average elapsed; Usage All projects table gains the repo hint; Quality per-project = Project (repo hint) | Reviewer rework (rate + n/d) | MR/PR revisions | Pipeline repairs | Review rounds; remove the Projects tab content, repositoryRows and other aggregates used only there; unused i18n keys removed.
- Test seams: e2e/statistics.spec.ts new all-projects test and the Trends test's Projects step; tests/routes.test.mjs admin normalization.
