## Design
The existing choice editor handles agent metadata. Launch preset catalog contains exact commands already exercised by test_executor.py/config.example.toml: OpenCode, Pi, Codex, Qwen. Only existing executor tables receive editable preset metadata. Backend validates command values at stage, direct PUT, pending presentation and apply; config validation remains final authority. Custom current values are displayed and shown as a disabled current dropdown entry, requiring selection of an allowed preset to Prepare. No new enrollment or generic shell text entry. Preserve revision/identity/pause/idle/locks/CSRF/admin checks. SettingsList header slot contains ModelConnection with heading layout; action right, existing status below. Credential component embeds its section inside SettingsList children. Existing endpoint and candidate review stay scoped.
Alternatives: Arbitrary shell command input rejected as unnecessary security expansion; automatic model fetching outside scope. Risk: choosing standard preset changes custom flags explicitly; review shows exact proposed command. No claims of installed CLI/model/provider acceptance.
