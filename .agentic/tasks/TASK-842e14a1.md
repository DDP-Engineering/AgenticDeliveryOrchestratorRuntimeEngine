## Design

### Approach
REQ-FUNC-e649b295: project ticket and job targets explicitly in History; retain the operation ID independently. REQ-FUNC-52b51a7e: terminal queue status and bound CLI results govern the shown result; preparation is not completion.
REQ-REL-b2482bf1: a small local SQLite deletion ledger in the ADORE home records an uncertain attempt before cleanup and confirms it after deletion. It works without web.db or web dependencies. History imports ledger rows transactionally into its existing audit store and records the import in the ledger to avoid duplication, including retention replays.
REQ-REL-f0affe2c: validate the ledger and its version, identity and permissions before cleanup; fail closed with typed errors. No bootstrap of the web store for CLI deletion.

### Interfaces and data
The ledger belongs to the local host account and stores only server-generated event ID, UTC time, stable project identity when known, job identity and result. A CLI actor is not a web account. An interrupted or unconfirmed deletion remains uncertain; confirmation follows successful cleanup. Existing web audit storage format stays unchanged. History maps its closed evidence to display types and outcomes without pretending preparation is execution. No prior stores are rewritten or migrated.

### Files and test seams
CLI and a standard-library ledger own deletion; web store and API expose it; worker validates command results; React History displays typed localized targets/results. Offline tests exercise isolated CLI, ledger corruption, worker, API and browser contracts. Update component and operator documentation and committed bundle.

### Risks and open decisions
The SQLite/filesystem boundary cannot be atomic: an interrupted cleanup remains uncertain. Ledger import must be idempotent and serialize with concurrent CLI writes. Project-scoped visibility requires verified immutable profile identity. No real stores or services are touched.

### Requirement map
REQ-FUNC-e649b295: typed target projection. REQ-FUNC-52b51a7e: verified terminal outcomes. REQ-REL-b2482bf1: external ledger with replay-safe import. REQ-REL-f0affe2c: validate before cleanup and fail closed.
