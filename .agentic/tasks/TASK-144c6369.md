## Design

Reuse the existing native backend, version check, plan/resource records and stage loop. Explicit retry alone reconciles environment_sha256, executable and executable_sha256, with stable policy equality for all remaining settings. Validate the saved plan file and exact runtime resource before refreshing; recover only verified owned scopes. Atomically replace the native receipt and plan, record old/new plan fingerprints, retain run/task/worktree identities and history. Native plan files compare parsed strict data rather than whitespace. Receipt refresh accepts the previous or already-current policy fingerprint so an interrupted refresh can be repeated explicitly; automatic conduction retains strict checks. Existing verify_required_tools performs the one bounded version probe before AEGIS.

Extend the existing terminal-result module for Retry with bounded schema/run/exit/reason binding. CLI recognizes a failed post-Retry run and returns nonzero. Worker reads the same persisted outcome already exposed by Jobs only for a bound retry_failed result; setup/lock/state/repository refusals use closed reasons, never stderr. Four-locale renderer reuses safe persisted failure evidence and localized guidance. No new abstraction or state schema; container recovery keeps its existing behavior.
