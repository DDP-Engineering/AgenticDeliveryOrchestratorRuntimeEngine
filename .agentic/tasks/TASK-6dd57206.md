## Design

Keep project selection for other pages; add an administrator-only All projects switch within Metrics. Compute one Metrics/Usage view from validated API responses. Aggregate additive counters, nullable costs and dated buckets; pool quality rates from cohort counts and cost efficiency from evidence-weighted totals. Pool duration samples from validated terminal summary spans, including zero, with selected-zone completion dates for period duration. Scope every auxiliary comparison/repository table to the selected project or all projects, with matching export links. Missing or pending data remains unavailable; request revision/session guards protect stale results. Preserve the server's RBAC and date filtering. Node's built-in offline test runner tests the TypeScript calculation module without added dependencies. GUI verification covers scope, tabs, filters, exports, empty results and responsive sizes.
