## Design

### Approach
REQ-FUNC-44463fc9 and REQ-FUNC-88b6455a: extend the pinned Pi catalog with exact per-provider model thinking capabilities; blank selection keeps Pi default, explicit selection is accepted only when supported. Pass the selection to Pi's native `--thinking` for stage and connection launches. Custom endpoints have Pi's default non-reasoning model definition; unknown models cannot claim explicit levels.
REQ-FUNC-1ab8feb0 and REQ-SEC-e28f8c02: retain redacted measured checks server-side under a bounded, expiring, unguessable one-use token scoped to administrator, draft and config revision. Creation consumes matching evidence at publication and stores it against the generated project identity and exact config; absent, stale, forged or malformed evidence cannot produce success. Preserve partial checks, including clone-dependent AEGIS files not checked.
REQ-UX-2946ca7f and REQ-UX-744de7c4: reuse existing localized labels and model datalist; localize check names, format timestamp, explain the two checks, render meaningful enum values and consolidate repeated local information. Show connected repository action as appropriate. Preserve path spelling, using a consistent server-provided path without case-folding Linux paths.

### Interfaces and data
Thinking is an optional closed string setting, default blank; invalid or unsupported explicit levels are rejected. Evidence tokens are opaque and carry no client-authored result. Existing readiness record remains strict, expanded to represent an unchecked AEGIS check; configuration revision changes make it stale. No data migration or automatic recreation.

### Files and test seams
Configuration, Pi catalog generation, launcher, native target, model connection, enrollment API and React wizard/settings/summary. Offline pytest at configuration, launcher, model connection and enrollment boundaries; focused web unit/browser checks; all four locales, help, operator/component documentation and generated bundle.

### Risks and open decisions
A check before clone cannot establish AEGIS files, so it remains partial after publication. Server restart expires pending evidence rather than trusting the browser. Preserve current secret redaction and role checks. The pinned Pi catalog and matching provider/model identity control the choice.

### Requirement map
REQ-FUNC-44463fc9, REQ-FUNC-d434c9f0 and REQ-FUNC-88b6455a: catalog and launcher; REQ-FUNC-1ab8feb0 and REQ-SEC-e28f8c02: server-owned check token and strict persisted evidence; REQ-UX-2946ca7f, REQ-UX-b781c764, REQ-UX-fa4e4c76 and REQ-UX-744de7c4: localized accessible controls and browser proof.
